# Видение

> Якорь реальности для агента: зачем существует проект и что есть прямо сейчас. Документ обновляется, а не дописывается.

## Название

Бот записи в барбершоп «Опасная бритва»

## Зачем проект существует

Клиент записывается на стрижку за минуту в Telegram, а владелец перестаёт отвечать на «а есть окошко в субботу?» в личных сообщениях по вечерам.

## Что есть сейчас

### Уже построено

- [x] Выбор услуги, мастера, дня и времени кнопками
- [x] Подтверждение записи клиенту и сообщение мастеру в общий чат
- [x] Напоминание клиенту за 3 часа до визита
- [x] Отмена записи клиентом по кнопке

### Ещё не построено

- [ ] Перенос записи на другое время (сейчас только отмена и новая запись)
- [ ] Панель владельца: расписание на неделю и выходные мастеров
- [ ] Предоплата

## Ценность

Для **клиентов небольшого барбершопа**, которым неудобно звонить и ждать ответа, бот — это **запись в два касания прямо в Telegram**, который **сразу показывает только свободное время**.

В отличие от **записи через личные сообщения владельца**, бот работает ночью, не путает время и сам напоминает о визите.

## Как поймём, что получается

| Показатель | Сейчас | Цель | Срок |
|------------|--------|------|------|
| Доля записей через бота | 0% | 60% | 30.11.2026 |
| Неявки без предупреждения | ~4 в неделю | 1 в неделю | 30.11.2026 |
| Сообщений владельцу про запись | ~25 в день | меньше 5 | 30.11.2026 |

## Чего мы не делаем

- Не делаем мобильное приложение и сайт: только Telegram.
- Не принимаем оплату в первой версии.
- Не ведём учёт клиентов и бонусную программу.
- Не подключаемся к сторонним сервисам онлайн-записи.
