# Предположения и ограничения

> Всё, на чём держится проект. Если чего-то здесь нет, агент додумает сам — и может ошибиться. Документ обновляется, а не дописывается.

## Технические

### Где и на чём работает

- **Хостинг:** самый дешёвый VPS, 1 ядро, 1 ГБ памяти.
- **База данных:** SQLite в одном файле. Записей мало, отдельный сервер базы не нужен.
- **Язык и среда:** Python 3.12, библиотека aiogram 3.

### Зависимости

| Библиотека или сервис | Версия | Зачем |
|-----------------------|--------|-------|
| aiogram | 3.x | Работа с Telegram |
| APScheduler | 3.x | Напоминания по расписанию |
| Telegram Bot API | — | Сам бот |

### Ограничения

- **Бюджет:** до 500 ₽ в месяц на сервер, платные сервисы не подключаем.
- **Сроки:** первая рабочая версия — к началу ноября, до предновогоднего наплыва.
- **Команда:** владелец и агент. Владелец не пишет код, но проверяет каждую фичу руками.

## Про пользователей и рынок

- Клиенты — мужчины 20–45 лет из района, большинство уже пишут владельцу в Telegram.
- Мастеров трое, график сменный, у каждого свои услуги.
- Клиенты хотят видеть свободное время сразу, без переписки.
- Сейчас запись идёт через личные сообщения владельца и тетрадку на ресепшене.
