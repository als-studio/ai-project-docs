# Описание продукта

> Единственный источник истины о том, каким должен быть продукт. Один документ на весь проект, а не по документу на фичу. Обновляется, а не дописывается.

**Продукт:** Бот записи в барбершоп «Опасная бритва»
**Версия описания:** 1.2
**Владелец:** владелец барбершопа
**Обновлено:** 30.10.2026

---

## Кто пользуется

### Клиент

- **Чего хочет:** записаться к своему мастеру на удобное время, не переписываясь.
- **Что мешает сейчас:** ждать ответа владельца, иногда до утра; путаница со временем.
- **Насколько разбирается в технике:** уверенный пользователь Telegram.

### Мастер

- **Чего хочет:** заранее знать, кто к нему придёт и на какую услугу.
- **Что мешает сейчас:** узнаёт о записи из тетрадки на ресепшене.
- **Насколько разбирается в технике:** новичок, нужен только общий чат.

### Владелец

- **Чего хочет:** не тратить вечера на переписку и видеть загрузку мастеров.
- **Что мешает сейчас:** 25 сообщений в день про запись, неявки.
- **Насколько разбирается в технике:** уверенный, но код не пишет.

## Главные сценарии

### Сценарий 1: Запись

```
Клиент жмёт «Записаться» → выбирает услугу, мастера, день, время → получает подтверждение
```

1. Клиент открывает бота и жмёт «Записаться».
2. Бот показывает услуги с ценой и длительностью.
3. Клиент выбирает мастера (или «любой свободный»), день и время из свободных слотов.
4. Бот подтверждает запись клиенту и пишет мастеру в общий чат.

### Сценарий 2: Напоминание и отмена

```
За 3 часа бот напоминает → клиент жмёт «Приду» или «Отменить» → слот освобождается
```

## Требования

### Т-1: Показывать только свободное время

**Что должно быть:** клиент видит только те слоты, где мастер свободен на всю длительность услуги.

**Готово, когда:**
- [x] Занятые слоты не показываются
- [x] Слот, в который услуга не помещается до конца смены, не показывается
- [x] Прошедшее время сегодняшнего дня не показывается

### Т-2: Одна запись — один слот

**Что должно быть:** два клиента не могут занять одно время у одного мастера.

**Готово, когда:**
- [x] При одновременной записи второй клиент получает «время только что заняли» и новый список слотов

### Т-3: Время всегда по часам барбершопа

**Что должно быть:** всё время в боте — местное время барбершопа, независимо от часового пояса сервера и клиента.

**Готово, когда:**
- [x] Слоты, подтверждения и напоминания показывают одно и то же время

---

## Общие требования

- **Скорость:** бот отвечает на нажатие кнопки быстрее 1 секунды.
- **Надёжность:** после перезапуска сервера напоминания не теряются.
- **Личные данные:** храним только имя из Telegram, его идентификатор и записи. Телефон не спрашиваем.

---

## Что не входит в эту версию

- Оплата — отложено до решения про предоплату.
- Отзывы и оценки мастеров — нет потребности.
- Запись нескольких человек за раз — редкий случай, владелец примет вручную.
