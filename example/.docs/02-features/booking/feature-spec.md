# Фича: Запись — что хотим

> Фича глазами пользователя: что ему нужно и как поймём, что готово.

## Намерение пользователя

```
Я как клиент барбершопа,
хочу записаться к мастеру кнопками в Telegram,
чтобы не ждать ответа и сразу видеть свободное время.
```

## Проблема

- **Как сейчас:** клиент пишет владельцу «есть время в субботу?», владелец смотрит тетрадку и отвечает, иногда на следующий день.
- **Что мешает:** долго, клиенты уходят в соседний барбершоп; бывают двойные записи.
- **Как должно стать:** клиент сам видит свободное время и записывается за минуту.

---

## Критерии готовности

- [x] **К-1:** клиент проходит путь «услуга → мастер → день → время» только кнопками, без ввода текста
- [x] **К-2:** показываются только слоты, где мастер свободен на всю длительность услуги
- [x] **К-3:** после записи клиент получает подтверждение, а мастер — сообщение в общий чат
- [x] **К-4:** за 3 часа до визита клиент получает напоминание с кнопками «Приду» и «Отменить»
- [x] **К-5:** клиент может отменить запись не позже чем за 2 часа до визита

### Граничные случаи

- [x] **Г-1:** два клиента жмут одно время одновременно — второй видит «время только что заняли» и обновлённый список
- [x] **Г-2:** клиент записывается на сегодня — прошедшее время не показывается
- [ ] **Г-3:** выбран «любой свободный мастер» — бот берёт мастера с наименьшей загрузкой в этот день
- [x] **Г-4:** до визита меньше 3 часов — напоминание не отправляется

### Ошибки

- [x] **О-1:** клиент пытается отменить запись позже чем за 2 часа — бот предлагает позвонить в барбершоп и показывает номер

---

## Путь пользователя

1. Клиент жмёт «Записаться».
2. Бот показывает услуги: «Стрижка — 1 500 ₽, 45 мин», «Борода — 900 ₽, 30 мин», «Стрижка + борода — 2 200 ₽, 75 мин».
3. Клиент выбирает мастера или «любой свободный».
4. Бот показывает ближайшие 7 дней, дни без свободного времени неактивны.
5. Клиент выбирает время.
6. **Итог:** «Вы записаны: стрижка у Артёма, сб 01.11, 14:30». Мастер видит запись в общем чате.

---

## Не входит в фичу

- Перенос записи — пока только отмена и новая запись.
- Выбор нескольких услуг подряд у разных мастеров.
