## Граничные случаи и ошибки

| Ситуация | Что должно произойти | Статус |
|----------|----------------------|--------|
| Г-1 Два клиента жмут одно время | Второй видит «время только что заняли» | ✅ |
| Г-2 Запись на сегодня | Прошедшее время не показывается | ✅ |
| Г-3 «Любой свободный мастер» | Берётся наименее загруженный | ⬜ |
| Г-4 До визита меньше 3 часов | Напоминание не отправляется | ✅ |
| О-1 Отмена позже чем за 2 часа | Предложение позвонить и номер | ✅ |

## Ручной сценарий

```
1. Открыть бота с тестового аккаунта, нажать «Записаться».
2. Выбрать «Стрижка», мастера Артёма, завтрашний день, первое свободное время.
3. Ожидаем: подтверждение с тем же временем, что было на кнопке;
   сообщение в тестовом чате мастеров с тем же временем.
```
