## Задача 1: База и справочники

**Статус:** ✅

**Что сделать:** создать таблицы `masters`, `services`, `bookings` и заполнить мастеров и услуги из `config.py`.

**Готово, когда:**
- [x] `python -m bot.db init` создаёт `data/bot.db`
- [x] Есть уникальный индекс на `(master_id, starts_at)` для активных записей

**Файлы:** `bot/db.py`, `config.py`

---

## Задача 2: Расчёт свободных слотов

**Статус:** ✅

**Что сделать:** функция `free_slots(master_id, service_id, day)` возвращает список свободного времени.

**Зависит от:** Задача 1

**Готово, когда:**
- [x] Учитывается длительность услуги и конец смены
- [x] Прошедшее время сегодняшнего дня не возвращается
- [x] Тесты в `tests/test_slots.py` проходят

**Как проверить:**
```bash
pytest tests/test_slots.py
```

**Зависит от:** Задача 2

**Файлы:** `bot/handlers/booking.py`

## Задача 4: Напоминания

**Зависит от:** Задача 3

**Готово, когда:**
- [x] Напоминание приходит за 3 часа по местному времени барбершопа
- [x] После перезапуска сервиса запланированные напоминания на месте

**Файлы:** `bot/reminders.py`
