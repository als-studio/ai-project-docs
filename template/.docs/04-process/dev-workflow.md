# Процесс работы

> Как работать с документацией день за днём. Слой необязательный, но помогает не забывать про логи.

## Цикл

```
Контекст → Решение → Работа
    ↑                  ↓
    └────── Лог ←──────┘
               ↑       ↓
         Проверка ←────┘
```

Не «сделал и надеюсь», а «сделал, проверил и записал».

---

## Одна рабочая сессия

### В начале: контекст

1. Агент читает `0-context/` — зачем проект и что есть сейчас.
2. Читает `01-product/prd.md` — каким должен быть продукт.
3. Читает папку текущей фичи в `02-features/`.
4. Просматривает свежие записи в `03-logs/` — что было в прошлый раз и какие баги открыты.

### В середине: работа

1. Берёт задачу из `dev-tasks.md`.
2. Делает её по пунктам «Готово, когда».
3. Проверяет по `test-plan.md`.
4. Меняет статус задачи.

### В конце: лог

1. Пишет в `implementation-log.md`, что сделано.
2. Если принято решение — пишет в `decisions-log.md`.
3. Если найден баг — пишет в `bug-log.md`.
4. Если что-то понял — пишет в `insights.md`.
5. Если изменилась система — обновляет `0-context/system-state.md`.

## Путь новой фичи

| Шаг | Что делаем | Документ |
|-----|------------|----------|
| 1. Что хотим | Намерение пользователя и критерии готовности | `feature-spec.md` |
| 2. Как строим | Устройство, данные, интерфейсы; решения — в журнал | `tech-design.md`, `decisions-log.md` |
| 3. Задачи | Разбиваем на атомарные задачи | `dev-tasks.md` |
| 4. Как проверяем | Проверка на каждый критерий | `test-plan.md` |
| 5. Работа | Выполняем задачи, пишем лог | `implementation-log.md` |
| 6. Запуск | Смотрим, что произошло в жизни | `validation-log.md` |
| 7. Выводы | Фиксируем, обновляем Якорь и Истину | `insights.md`, `vision.md`, `prd.md` |

## Какой документ когда обновлять

| Документ | Когда | Как |
|----------|-------|-----|
| vision.md | Меняется цель или появилось новое «что есть сейчас» | Переписать |
| assumptions.md | Подтвердилось или опровергнуто предположение | Переписать |
| system-state.md | Изменилась система | Переписать |
| prd.md | Изменились требования | Переписать |
| feature-spec.md | Изменились границы фичи | Переписать |
| tech-design.md | Изменилось устройство | Переписать |
| dev-tasks.md | Задача сделана | Поменять статус |
| decisions-log.md | Принято решение | Дописать сверху |
| implementation-log.md | Закончена сессия | Дописать сверху |
| bug-log.md | Найден или исправлен баг | Дописать сверху |
| validation-log.md | Был запуск | Дописать сверху |
| insights.md | Появился вывод | Дописать сверху |
